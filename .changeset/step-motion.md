Add step-transition motion, on by default and with nothing to import: a small stylesheet is built into the package and added to `<head>` when it loads (the way Sonner does it), using `:where()` selectors so your own classes win. `Tour.Content` now stays mounted across steps and the card glides between targets (`transform` only). It scales in from 0.96 and fades on open, and fades out on close through Radix's own exit handling. The spotlight cut-out follows with the same duration and ease, and the title and description fade in on each step. Tune it with the `--tour-duration` and `--tour-ease` CSS variables, turn it off with `<Tour.Root motion={false}>`, and style it with the new `data-motion` (`from-start` or `from-end`) and `data-placed` attributes on `Tour.Content`. `prefers-reduced-motion` removes movement and keeps a short opacity fade. `Tour.Root` now stays rendered while closed so the card can fade out; do not unmount `Tour.Content` yourself between steps. The spotlight CSS recipe from the docs is no longer needed. A Content-Security-Policy that blocks inline `<style>` tags needs a nonce or `'unsafe-inline'`, or `motion={false}` with your own CSS.
